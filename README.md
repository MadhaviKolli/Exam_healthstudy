# Exam_healthstudy
Individuell uppgift – Hälsostudie

Projektöversikt

Detta projekt analyserar en datamängd från en hälsostudie med hjälp av Python, NumPy, Pandas, matplotlib, Scikit-Learn och bibliotek för datavisualisering.

Projektet omfattar:

- Deskriptiv statistisk analys
- Confidence Interval
- Hypothesis Testing
- Linjär regression för att förutsäga systoliskt blodtryck
- Principal komponentanalys (PCA)
- Datavisualiseringar
- Modulär Python-kod
- En objektorienterad implementation med klassen HealthAnalyzer

 
 Datamängd
 
Den datamängd som används är:
health_study_dataset.csv

Datamängden innehåller information om:

- Ålder
- Kön
- Längd
- Vikt
- Systoliskt blodtryck
- Kolesterol
- Rökvanor
- Sjukdomsstatus

Installation

Skapa och aktivera en virtuell miljö och installera nödvändiga paket:
pip install -r requirements.txt


Öppna och kör:

notepad/analys.ipynb

notebook/health_analysis.ipynb

via Jupyter Notebook eller VS Code.
